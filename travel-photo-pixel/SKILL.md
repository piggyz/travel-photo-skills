# 像素旅行照片

把用户上传的照片作为图像编辑目标，生成一张可辨认的像素游戏效果图。先读 [references/prompt.zh-CN.md](references/prompt.zh-CN.md)，将可改参数替换成原照片的事实。不要机械复用本期江南老街的桥、红灯笼或无人场景。

## 处理照片

1. 先查看输入图，识别主景的轮廓和数量、左右/前后关系、道路或水面的走向、一个醒目细节、主要色彩；这些是后续修改仍应保留的识别线索。人像只保留输入已存在的人物与可见特征，不从风景示例引入新角色。
2. 默认保持原图比例和主景；用户指定新比例时优先保住地标和人物，不拉伸或为了排版切掉主景。场景内容与视角是否允许改变以用户要求为准。
3. 方形像素簇、一致基础尺度、阶梯轮廓；不是照片加马赛克滤镜。
4. 用支持参考图编辑的图像工具执行；有内置图像编辑工具时直接使用。没有能接收这张图的图像工具时，只交付适配后的提示词并说明无法在当前环境生成，不把滤镜、HTML/SVG 示意或不存在的文件说成成品。

## 对照与调整

出图后查看原图和结果，先核对主景数量、轮廓、相对位置与醒目色点，再看材质是否成立。像素太碎时合并色簇，主景模糊时先修复轮廓与位置；不要用平滑模糊掩盖问题。 每轮优先修正最明显的一项，仍以原照片为参照，不把不断重绘的结果当成地点事实。小人物或小字可能被概括；明显的主体改动应修正或明确说明。

输出完成图片和可用保存位置。原图保持原样，成品另存。不要自动发布、给他人发送私信或安装其他工具。

## 示例和范围

[references/example-prompt.en.txt](references/example-prompt.en.txt) 是本期老街示例实际使用的英文提示词，需要参考示例实现时读取；用于新照片时替换场景描述。本 Skill 的详细中文模板用于复用和调整，没有逐一在不同旅行照片上验证，不承诺不同模型和版本得到完全一致的结果。

本工作流生成像素风格视觉图片，不保证精确的格点、索引色或游戏引擎可直接使用的资产格式。
