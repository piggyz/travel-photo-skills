# 像素旅行照片：可复制详细 Prompt

上传照片后，把下面整段发给支持参考图编辑的图像工具。方括号是可改变量，不必填写全部；工具应按照片判断没有填写的部分。

请直接编辑我上传的照片，制作一张细节清楚、具有游戏场景美感的像素风图片。下面方括号中的内容是可改参数；如未填写，先从照片判断再使用默认设置。照片是唯一场景来源，不能只按“旅行”这个主题另画一处地方。

【一、原图锁定】
识别并保留这些信息：[主景或地标]、[左右/前后关系]、[视线或道路/水面走向]、[最醒目的小细节]、[原图主要颜色]。保留主景的数量、轮廓、大小关系和大致透视；原图有人就保留人物数量、所在位置、姿势与主要衣着颜色，原图无人就不要增加角色。建筑不要变成通用城堡，海岸不要多出照片里没有的岛，街道不要改成另一条路。小字、路牌和不可辨认的细部可以简化，不编造具体文字。

【二、构图】
默认保持原图宽高比、相机高度与主景位置，把整个画面重新画成连贯的像素场景；不要在照片上盖一层方块滤镜。保留主要景物，不为了凑竖图任意裁去桥、塔尖或人物头部。用户指定 3:4 时，优先在完整保留主体的前提下调整景物周围留白，不拉伸画面。近景像素轮廓稍清楚，远景用更少的色块，靠大小和色彩对比表现空间。

【三、像素结构】
让方形像素和像素簇清楚可见：斜线形成有节奏的阶梯，建筑轮廓用连续色簇，树叶用成片的块面，水面倒影使用横向断续色块。全图采用一致的基础像素尺度，建议从“中等颗粒、能看出像素又能识别地标”的状态开始，而不是把每个摄影细节压成噪点。接近 16 位冒险游戏背景的丰富度；这一名称指视觉气质，不表示文件真的只有 16 位色深。禁止圆豆颗粒、玩具塑料、高分辨率细线、平滑渐变、抗锯齿光边和混在其中的摄影纹理。

【四、配色与光影】
从原图提取主色，整理成约 18—28 个视觉上有区别的颜色，这只是画面控制目标，不要求输出精确索引色。保留照片中承担辨识作用的颜色，例如红灯笼、蓝海水或黄色车厢；不要为了“好看”把地方改成霓虹城市。光的方向跟随原图，用少量阶梯色带区分受光面、背光面和倒影。轮廓颜色来自照片里最深的暗色，不给所有物体加同样粗的黑边。

【五、避免项】
不添加游戏界面、血条、任务文字、地图标记、人物头像、金币、包装、边框、品牌标志和水印；不新增地标或幻想道具。不要马赛克审查效果，不模糊像素边缘，不产生照片与像素拼接的中间状态。输出一张完整风格图，不额外输出分析表或多个候选拼图。

【六、出图后的改法】
若更像马赛克滤镜，重新组织屋顶、植被、水面为主动绘制的像素簇，减少孤立噪点。若主景认不出，先恢复[地标/主体]的轮廓、位置和与邻近物体的关系，再增加细部；若颗粒太细，就增大基础像素并合并相近颜色。每次优先修正一项，不同时更换场景、色调和视角。保留这张原图作为参照，不用多轮风格图代替原图。
